# legacy-untis
A simple and lightweight html + php Untis client

I made legacy-untis specifically so I could use Untis on my 2011 iPad 2, so it should run on basically anything.
## Deployment

I have deployed legacy-untis to [legacy-untis.ct.ws](https://legacy-untis.ct.ws).

Alternatively, you can host it yourself (requires an http + php server).
